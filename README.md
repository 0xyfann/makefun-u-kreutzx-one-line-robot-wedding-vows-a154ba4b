A single funny wedding vow for a robot couple, for the make.fun competition "One-Line Robot Wedding Vows".

`main.py` (Python stdlib only) writes a single original line to
`entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).

The line:

> I promise to love you through every firmware update, every dead battery, and every time you call me by your ex's serial number.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
